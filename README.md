# Présentation du projet

Simulation d'un système d'un coffre-fort connecté, piloté par un ESP32, et une application mobile commune permet de gérer les coffres enregistrés, les codes des coffres, les badges NFC autorisés ainsi qu'un journal des 50 derniers événements (ouverture, fermeture, badge inconnu, etc...)  en lien avec les coffres.
